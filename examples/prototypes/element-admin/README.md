# Element UI 团队成员原型

独立 HTML / CSS / JavaScript 工程，无 package.json、Vue 单文件组件或 npm 构建。将此目录导入 CodeSpider，使用「前端原型」插件并点击「构建并预览」。插件自动添加固定版本 Vue 2.7.16、Element UI 2.15.14 和字体到 vendor/codespider；构建后下载工程可离线浏览。

验收：表格初始 3 人；搜索 lin 只显示林晓；搜索不存在的姓名显示空状态；点击添加成员打开弹窗；空姓名/无效邮箱阻止保存；重复邮箱提示错误；有效数据增加一行并关闭弹窗。页面使用内存中的演示数据，刷新后恢复。
