# 会话保存与过程折叠

项目对话在开始模型生成前保存用户需求，生成完成后关联原 Task；失败时保存错误。任务正文、补丁、工具事件和执行结果复用现有任务存储。自由对话保存用户消息和回复。登录模式下对话记录使用现有 H2 存储，本地免登录模式使用开发用 JSON 存储。

打开工程或自由对话时自动读取当前账号的记录。待审批任务恢复批准入口；执行中任务继续查询事件；成功、失败或取消的任务恢复为不可重复批准的状态，不产生新的模型调用或积分消耗。

任务进入终态时，自动关闭该任务的全部思考、方案、补丁和工具详情，包括当前未显示工程中的节点。正文及执行结果继续显示，用户可以再次展开详情。其他任务的展开状态不受影响。

## 接口与归属

- `GET /api/conversations?workspace_id=<id>`：读取当前用户在指定工程的历史。省略工程 ID 时读取自由对话。
- `POST /api/conversations/free`：保存 `{ "text": "消息" }` 并返回回复。
- 现有 `POST /api/tasks` 自动关联会话记录；创建 Task 时写入服务端认证用户的 `owner_id` 和 `conversation_turn_id`。客户端不能指定归属。
- Task 详情、事件、批准及取消接口校验任务归属；旧版未归属任务仅管理员可访问，不自动并入个人历史。

历史按账号、工程隔离，退出或切换账号时清空浏览器缓存，并使旧请求和轮询失效。模型生成期间刷新页面，会恢复等待状态并查询生成结果；服务重启导致的未完成生成请求显示中断提示，不自动重发。源码读取确认被拒绝时尚未开始模型生成，不建立该轮工程记录。

## 验证与边界

103 项 Python 回归及 4 组前端脚本通过。覆盖 H2 关闭重开、并发保存、任务完成后恢复、生成失败留存、账号隔离、越权审批拒绝、待审批恢复、执行轮询恢复、旧账号响应失效、终态折叠与事件去重。真实 DOM 检查验证了嵌套详情关闭和恢复后的按钮状态。

此功能保存更新后的会话；旧版仅存在浏览器内存中的消息无法在关闭页面后补回。目前每个工程保留一份连续对话，自由对话单独保存。没有增加自动重执行、删除历史或多会话分支行为。

发布复用独立 release 目录与健康检查。数据格式新增可选字段及 `conversation_turns` 集合，不修改账号、余额和历史事件。立即发布失败可切回旧 release；已有新任务后降级到不识别新增 Task 字段的旧版本，需要同步处理数据兼容，不能只切换程序目录。
