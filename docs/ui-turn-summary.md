# 每轮对话的整体折叠

完成、失败、取消时，将当前 task_id 对应的方案、审批过程、工具请求、重试、文件写入、结构审查、命令输出及失败原因归入同一个「执行过程」折叠区。区外仅展示一个最终结论段落；初始方案和按钮都移入折叠区。

折叠只改变前端呈现，保留原事件和 DOM 节点，展开可继续查阅。账号/工程/task_id 独立绑定；审批中的其他任务继续可操作。重复终止事件与状态轮询不重复添加结论，也不会强制重新关闭用户主动展开的已完成过程。

重新登录或恢复历史时使用同一渲染逻辑。历史任务缺少终止事件时，从持久化任务状态和错误生成结论。生成阶段失败且尚未创建任务时维持原有单条失败回复。

验证：4 组前端回归、真实浏览器 tests/frontend_turns.cjs 及弹窗回归。新增浏览器验证覆盖三种终止状态、完整过程展开、每轮单一结论、待审批轮次隔离、切换工程、历史恢复、无终止事件的旧失败任务。所有测试使用模拟 API，不执行实际命令或再次扣费。
