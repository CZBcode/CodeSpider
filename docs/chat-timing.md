# 对话动画与时间

自由聊天和项目生成显示三点跳动的「思考中」指示，每秒刷新等待时间。批准项目任务后，执行状态同样显示动态指示和本轮已用时间。成功、失败或取消后停止动态指示，完成任务仍保持整轮过程折叠、单段结论的展示。

用户消息下方显示发送时间；回复或最终结论下方显示结束时间与耗时。今天显示时分秒，其他日期显示日期和时间；悬停可查看完整时间，按浏览器本地时区展示。支持系统“减少动态效果”偏好，此时圆点静止，计时仍更新。

`conversation_turns.finished_at` 保存服务端生成结束时间，`created_at` 为该轮服务端开始时间。API 在自由聊天响应、任务响应和会话历史中提供 `timing`：`started_at`、`response_finished_at`、`finished_at`、`generation_duration_ms`、`duration_ms`。项目任务终态结束时间来自持久化任务的 `updated_at`，实时终止事件可先更新界面。任务持久结构没有新增字段，`timing` 仅在响应中计算。

“生成耗时”为服务端该轮开始至生成完成；“本轮耗时”为开始至项目执行结束，包含用户确认等待。请求发出但尚未返回时，浏览器显示本地等待时长；HTTP 错误在当前页面显示本次等待耗时，重新打开历史后以服务端记录为准。服务端开始时间不包含请求在会话锁中排队的时间，包含项目源码上下文读取。

旧自由对话若缺少结束时间、或者服务重启导致生成中断，不伪造耗时，显示“耗时未记录”。旧项目任务可从持久化开始/结束时间恢复。历史消息恢复不会用页面刷新时间替换原聊天时间。原文和15轮上下文策略不变。

验证覆盖：服务端准确时差、历史缺失/无效时间、H2重启、自由聊天API与历史一致；真实Chrome桌面/手机的动画、实时计时、减少动态效果、成功/失败/取消停止、历史恢复，以及原有任务折叠和账户隔离回归。

发布为独立版本目录，备份H2与JSON。新增会话字段向前兼容旧版读取；回退程序无需覆盖聊天/积分数据，已保存结束时间可继续保留。
