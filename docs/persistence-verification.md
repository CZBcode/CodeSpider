# 持久化核查（2026-10-14）

## 结论与保存位置

已提交的对话、项目配置、任务结果和写入磁盘的产物不会因为退出登录而删除，也没有按会话或时间自动清理的逻辑。登录凭证有效期为 14 天；凭证过期不等于数据过期。

| 数据 | 存储位置 | 恢复方式 |
| --- | --- | --- |
| 账号、自由对话、项目对话正文 | 数据目录 `h2/accounts.mv.db` | 同一账号登录后按账号及工程查询 |
| 项目配置 | 数据目录 `workspaces.json` | 登录后重新加载项目列表 |
| 任务、补丁、执行事件 | 数据目录 `tasks.json`、`events.json` | 与已保存对话关联，恢复时不重新执行或扣费 |
| 源代码、文档等产物 | 各工程实际目录，包括 `CODESPIDER.md` | 文件树、产物页及工程 ZIP 下载 |
| 符号索引 | 工程中的索引缓存，可从源码重新构建 | 按现有安全策略读取和更新 |

线上服务数据目录为 `/var/lib/codespider/.codespider`，与 `/opt/codespider` 指向的程序发布目录分离。核查时两个工程目录均存在，其中一个已有 `CODESPIDER.md`。开发免登录模式的对话使用 `accounts-dev/` JSON，不能与生产 H2 模式混用来判断数据是否丢失。

## 本次修复

- 产物页此前只展示本次生成的文档，重新打开工程会错误显示“未生成”。新增标准工具 `document.read`，重新进入产物页时读取已保存文件，不重新生成，不覆盖用户编辑，不调用模型。
- 文件未生成、读取需确认、读取失败分别显示，安全模式依然需要用户确认读取。
- 退出、切换工程、同时生成文档时，旧读取结果不会覆盖新页面。
- 同一页面重新登录后回到首页，避免显示清空后的旧工程或自由对话页面；进入工程或自由对话时恢复历史。
- 兼容历史失败事件中使用 `message` 保存的错误信息。

本地全量 Python 回归 114 项通过，H2 测试实际执行。4 组前端脚本通过，新增覆盖产物恢复、安全确认、读取失败、旧响应失效及重新登录落地页。

服务器以 `codespider` 用户在隔离临时目录再次运行上述 H2 + daemon 完整测试，通过。修复发布到 `/opt/codespider-releases/20261014-persistence`；发布前确认无执行中任务或生成请求，停止服务后备份 H2 和顶层 JSON 至 `/var/backups/codespider/persistence-20261014`。发布前后逐项比对账户、对话、用量、模型、项目、任务、事件及现有文档的摘要，完全一致。旧 release 路径保存在备份目录的 `previous-release.txt`，回滚只需恢复程序软链接并重启服务，无需数据迁移。

复验命令：

## 边界

- “持久保存”不是磁盘损坏或人为删除后的恢复保证。备份需要同时覆盖 H2 数据库、JSON 数据和所有工程目录；本次不增加自动异地备份。
- 本报告发布时项目列表及项目文件仍为共享。后续用户隔离与市场版本已增加工程归属、工具权限和服务器执行沙箱，见 [用户隔离与能力市场](user-isolation-and-market.md)。
- 未发送草稿、终端页面临时输出不属于已保存对话；正在运行的进程不会随服务重启自动恢复。
- 历史版本仅存在浏览器内存中的消息无法补回；同名工程的物理文件也不是版本归档，后续覆盖会替换文件内容。
